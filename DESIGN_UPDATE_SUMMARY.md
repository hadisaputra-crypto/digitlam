## 🚀 Cara Lihat Desain Baru

### 3 Langkah Mudah:

**1. Build Assets**
```bash
cd c:\xampp\htdocs\repository_jurnal
npm install
npm run dev
```

**2. Jalankan Server (Terminal Baru)**
```bash
cd c:\xampp\htdocs\repository_jurnal
php artisan serve
```

**3. Buka Browser**
```
http://localhost:8000
```

Done! ✨
