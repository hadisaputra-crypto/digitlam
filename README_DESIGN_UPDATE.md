## 🔄 Maintenance

### Untuk menambah komponen baru:
1. Gunakan `.card-surface` untuk cards
2. Gunakan `.btn-refined` untuk buttons
3. Gunakan gradient text untuk judul
4. Gunakan matching warna untuk icons

### Contoh:
```html
<div class="card-surface p-6 rounded-xl">
    <h3 class="text-xl font-bold text-transparent 
        bg-gradient-to-r from-blue-600 to-indigo-600 bg-clip-text">
        Title
    </h3>
    <p class="text-gray-600">Description</p>
    <button class="btn-refined mt-4">Action</button>
</div>
```
